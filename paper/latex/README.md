# LaTeX Project for Overleaf

This directory contains the self-contained LaTeX source for the paper:
**"Automated Rooftop Solar Photovoltaic Detection and Instance Segmentation from High-Resolution Aerial Orthomosaics"**

## 📁 Directory Structure
- `main.tex`: Complete IEEEtran LaTeX source code matching the Typst paper.
- `template.tex`: Original IEEEtran conference template reference.
- `figures/`: Complete directory containing all 39 high-resolution PNG plots, sample chips, confusion matrices, and comparison grids.

## 🚀 How to Upload to Overleaf
1. Select all files and the `figures/` folder inside `paper/latex/`.
2. Compress into a `.zip` archive:
   - `main.tex`
   - `figures/`
3. On [Overleaf](https://www.overleaf.com/):
   - Click **New Project** $\to$ **Upload Project**.
   - Select the `.zip` file.
   - Set the compiler to **pdfLaTeX** (default in Overleaf).
4. Click **Recompile**.
